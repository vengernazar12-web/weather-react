# WEATHER_REACT

  Website for checking the weather

## 🚀 Features
- City search functionality
- Current weather and information display
- Day selection cards
- Hour selection cards

## 🛠 Tech Stack
- React
- HTML
- SCSS

## 🚦 Application States
- **Loading**: Displayed while fetching data
- **Success**: Displayed when weather data is found
- **Not Found**: Displayed when the searched city is not found
- **Error**: Displayed when an error occurs during the request
